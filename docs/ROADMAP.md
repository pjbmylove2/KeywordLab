# 개발 로드맵

각 단계는 끝나면 바로 써볼 수 있는 상태가 되도록 나눴다. 단계마다 브랜치 하나, PR 하나.

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 솔루션 뼈대, 다크 테마 레이아웃, 사용자 비밀, CI 빌드 | 완료 |
| 1 | 네이버 검색광고·블로그 검색 연동, 키워드 직접 조회 화면 | 완료 |
| 2 | 주제·제목 확정: 제목 템플릿, 제목 점수, Codex용 입력 블록 복사, 넘긴 기록 저장(SQLite) | 완료 |
| 3 | 구글 트렌드 RSS·자동완성 수집기, 키워드 점수, 오늘의 이슈 키워드, 설정 화면 | 다음 |
| 4 | 트렌드 보기: 네이버 데이터랩 추이, 패턴 판별, 관련 뉴스, 누적 흐름 | |
| 5 | 로컬 자동 실행: Windows 작업 스케줄러로 수집기 정기 실행 | |

## 2단계 완료 기준

- 키워드 직접 조회 결과에서 "제목 정하기"를 누르면 티스토리/네이버 제목 후보와 점수가 나온다.
- 티스토리: 40자 이내 가점. 네이버: 같은 단어 반복·과장 표현 감점. 금지 표현은 설정값.
- 확정한 제목으로 Codex용 입력 블록을 복사하면 키워드·플랫폼·제목·패턴·시각이 SQLite에 저장된다.
